# TRAPS 2.0 TEST - version 3

Démonstration Android entièrement hors connexion, fondée sur les écrans d’APK108.

## Installation

Télécharger le fichier APK depuis https://github.com/sdebliquy35-source/TRAPS-2.0-TEST/releases/latest puis l’ouvrir sur Android. Autoriser l’installation depuis le navigateur si Android le demande. Cette version remplace l’ancienne TRAPS 2.0 TEST ; elle cohabite avec l’application de course TRAPS 2.0. Les avertissements Android restent à la décision de l’utilisateur. Aucun compte GitHub nécessaire.

## Démarrer

Choisir Slalom ou Time Trial Kayak Cross, puis le rôle sur l’écran habituel. Les données existantes du test sont conservées. Les chronos utilisent l’heure du téléphone.

- Slalom : 30 dossards (1-30), 10 portes, postes 1 (1-5), 2 (6-8), 3 (9-10). Portes rouges 3, 4, 7, 10 ; autres vertes.
- Cross : 10 dossards (1-10), zones 1 START, 2 porte 1 verte, 3 esquimautage E, 4 porte 2 rouge. Les zones gardent le routage de l’application actuelle, mais aucune donnée ne part sur le réseau.

## Tester les fonctions

Saisir les pénalités et justifier par schéma, note manuscrite, clavier ou audio. Les modes Fiches et Boutons sont disponibles en slalom. Le micro peut nécessiter votre autorisation. Les sauvegardes sont locales.

Revenir au choix des fonctions. Reprendre le poste ou choisir Changer de poste : confirmer la libération simulée, puis choisir le nouveau poste et son nom. Les fiches restent disponibles en reprenant un poste. Passer au rôle Juge Arbitre pour rechercher un dossard et une porte et consulter sa justification. Sur ce téléphone seulement : il n’y a pas d’échange entre téléphones.

Chrono départ et Chrono arrivée sont accessibles dans les deux disciplines. Le bouton doit être ouvert pour saisir un temps. Absence et dessalage simulent les blocages et les annulations sur cette Test. Les pénalités déjà saisies sont protégées dix minutes après une arrivée enregistrée.

Deux messages fictifs arrivent à des moments variables de la course, pendant l’utilisation des écrans de saisie : En attente, Lire, puis le pouce pour confirmer que l’action est réalisée. Aucun message externe ne peut être envoyé ou reçu.

## Réinitialiser

Depuis l’accueil, Réinitialiser les deux compétitions efface pénalités, justifications, chronos, signalements, messages et sauvegardes de test. Retour à l’accueil, deux compétitions vierges. Aucun résultat d’une application de course n’est touché.

## Limites

Ce test vérifie l’ergonomie et les parcours locaux. Il ne teste ni réseau, ni réception réelle, ni synchronisation entre appareils. Les mentions de sauvegarde/confirmation sont explicitement simulées. Pas de recherche de mise à jour dans cette application sans permission Internet ; télécharger manuellement une nouvelle Test à ce même lien.
